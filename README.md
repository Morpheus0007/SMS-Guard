# SMS Guard — Детектор фишинговых SMS

Проект команды для **Осеннего хакатона INAI 2026** (ТЗ 1 — «Детектор фишинговых SMS»).  
Определяет вероятность мошенничества в SMS на **русском**, **кыргызском**, **смешанном языке** и **латинском транслите** (включая обфусцированный текст), выставляет оценку риска `0..100` и объясняет сработавшие причины.

---

## Быстрый старт (одной командой)

> Решение работает полностью локально и оффлайн. Ядро, обучение `models/model.pkl`, `evaluate.py`, `main.py` и `pytest` не требуют внешних API-ключей и запускаются даже на чистом Python 3.10+.

### 1. Установка зависимостей
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
# source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Запуск веб-интерфейса одной командой
```bash
python run.py
# или напрямую:
streamlit run app.py
```

### 3. Оценка модели на CSV (`evaluate.py`)
```bash
python evaluate.py data/sms_dev.csv
```
Поддерживаются оба формата CSV:
- размеченный (`id,text,label`) → выводит `Accuracy`, `Precision`, `Recall`, `F1` и `Confusion Matrix` (добавьте `--errors` для вывода ошибочных примеров);
- неразмеченный (`id,text`) → сохраняет `predictions.csv` (`id,label,risk,score`) и печатает сводку по рискам.

### 4. Проверка одного SMS из CLI (`main.py` и Python API `detector.check`)
```bash
python main.py "С р о ч н о ! Ваша SIM-к@рт@ будет заблокирована. Перезвоните на 0770 553707"
```
Выводит в `stdout` строго валидный JSON:
```json
{"risk": "high", "score": 99, "reasons": ["указан контактный номер телефона", "угроза блокировки или отключения карты, аккаунта или SIM", "создание срочности или ограничения по времени", "просьба перезвонить или позвонить по указанному номеру"]}
```
Запуск `python main.py` без аргументов открывает интерактивный режим.

### 5. Переобучение модели (`models/model.pkl`)
```bash
python -m src.train
```
Обучает L2 Logistic Regression + Word `(1,2)` / Char_wb `(3,5)` TF-IDF **строго на `data/sms_train.csv`**, подбирает гиперпараметры и сдвиг `score_shift` (в логитах) под границу `score >= 65` через **5-fold Stratified CV**, и сохраняет переносимый Pickle `models/model.pkl` по контракту v3.1.

### 6. Тесты (`pytest`) и бонусный Telegram-бот (`bot.py`)
```bash
pytest -v
```
Для запуска Telegram-бота скопируйте `.env.example` в `.env`, впишите токен от `@BotFather` и выполните:
```bash
python bot.py
```

## Что сделано

### Обязательные требования ТЗ
- **Деобфускация и нормализация (`src/preprocessing.py`):** извлечение URL и телефонов до замен (цифры телефонов, дат, сумм и OTP-кодов не искажаются), линейная $O(N)$ склейка разреженных букв (`к о д -> код`, `в ы и г р а л и -> выиграли`), замена гомоглифов и leetspeak (`Ванk`, `б@нк`, `B@nk`, `0->о`, `3->з`, `6->б`, `@->а`, `u->и`), кыргызский (`ң/ө/ү`) и транслитерация латиницы в кириллицу (`kodduu jiberiniz`, `kartanyz bogottoldu`, `soobshite kod`).
- **12 канонических признаков (`src/features.py`):** 8 базовых из ТЗ + `has_official_domain`, `has_brand_spoof_domain`, `has_safe_warning` («никому не сообщайте / эч кимге айтпаңыз»), `has_phone_number`. Флаг `was_obfuscated` **не используется** как признак мошенничества (так как обычные `ok` SMS в данных тоже бывают обфусцированы).
- **Веса обучены на `sms_train.csv` (`src/train.py`, `models/model.pkl`):** без ручного хардкода весов, с калибровкой под `high >= 65`.
- **Единый формат `check(text)` (`src/detector.py`, `detector.py`):** `{"risk": "low"|"medium"|"high", "score": int, "reasons": list[str]}` (`low < 30`, `medium 30..64`, `high >= 65`).
- **Скрипт оценки (`evaluate.py`) и CLI (`main.py`).**

### Бонусные и инженерные возможности
- Проверка доменов по строгому официальному белому списку (`beeline.kg`, `balance.kg`, `nbkr.kg`, `mbank.kg` и их поддомены) + детекция имитации брендов и кириллических гомоглифов в доменах.
- Персонализированные советы абоненту «что делать» (`src/advisor.py`).
- Интерактивный веб-дашборд на Streamlit (`app.py`): 4 демо-пресета, «Рентген текста» (до/после деобфускации), разбор вклада признаков, пакетная проверка CSV и график весов модели.
- Асинхронный Telegram-бот на `aiogram 3.x` (`bot.py`) с HTML-экранированием, инлайн-примерами и советами.
- Автоматический тестовый набор (`tests/`, 49 тест-кейсов + независимый `tests/blind_test.csv` на 50 SMS) и пакет `colab_starter/` для бесшовной интеграции модели от ML-участников.

### Статус выполнения требований
Все обязательные требования ТЗ 1 и запланированные бонусные модули (Streamlit-интерфейс, Telegram-бот, строгая проверка доменов по белому списку, советы абоненту, 49 автотестов) выполнены полностью и проверены. Для запуска Telegram-бота в сети Telegram достаточно указать собственный `TELEGRAM_BOT_TOKEN` в `.env`.
